# TASK PROMPT: Multi-Bookie Odds Filtering & Betslip Generator (betPawa & SportyBet Kenya)

You are tasked with building a Next.js (App Router, TypeScript, Tailwind CSS) web app that fetches live football match odds, runs local filtering against strict preferred market criteria, randomly picks N matches, and converts the selections into a single booking code for betPawa Kenya (`betpawa:ke`) or SportyBet Kenya (`sportybet:ke`).

---

## 1. TECHNICAL ARCHITECTURE (Zero-DB In-Memory Pipeline)

- **Frontend:** Next.js App Router UI with responsive mobile layout, sticky bottom betslip drawer, and filter pills.
- **Backend Routing:** 
  - `GET /api/odds`: Ingests and normalizes live soccer match odds in memory.
  - `POST /api/generate-code`: Packages selected match market IDs and sends them to the ConvertBetCodes API to return a destination booking code.

---

## 2. STRICT DATA MATCHING & PARSING RULES

### Common Grep/Regex String Pitfalls
1. **Diacritics & Team Name Mismatches:** Teams like "Bayern München" vs "Bayern Munich" or "Atlético Madrid" cause string matching failures. Always normalize team names to lowercase, lowercase ASCII without accents (`NFD` normalization: `.normalize("NFD").replace(/[\u0300-\u036f]/g, "")`) before matching.
2. **Special Characters in JSON Strings:** Characters like `&` (e.g., "Brighton & Hove Albion"), hyphens, and single quotes (`'`) break strict regex lookups. Strip non-alphanumeric characters when performing ID maps.
3. **PAGINATION & ACTIVE MATCH DISCOVERY:** Odds APIs return paginated responses or omit active live games if requested with `prematch` parameters.
   - You MUST loop through all API response pages to ensure no matches meeting the odds constraints are missed.
   - Filter out games where status is `IN_PLAY`, `CANCELLED`, or `POSTPONED`.
   - Kickoff times must be strictly mapped using UTC ISO timestamps (`kickoff >= NOW()` and `kickoff <= NOW + selected_timeframe`).

---

## 3. PREFERRED MARKET FILTERING ENGINE (`src/lib/filterEngine.ts`)

Implement array processing logic that scans every fixture and pulls ONLY outcomes matching these thresholds:

1. **Double Chance (1X, X2, 12):** Decimal odds range between `1.08` and `1.20`.
2. **Home Win (1):** Decimal odds range between `1.30` and `1.50`.
3. **Over 0.5 Goals:** Market outcome for Over 0.5 Total Goals.
4. **Under 3.5 Goals:** Market outcome for Under 3.5 Total Goals.

*Selection Constraint:* Ensure each game displays its league name, kickoff time, normalized team names, selected market description, and exact decimal odds cleanly on card containers.

# ui-no-redundancy

Before finalizing any UI:

1. List every piece of information shown on the screen/component and where it appears.
2. Each fact appears exactly once, in the place that serves it best (page/section title, icon + text, summary banner vs. the table beneath).
3. Don't restate derived or implied information: a team name shown twice, a heading repeated by the row above, labels duplicating context.
4. When unsure whether something is redundant, ask the user rather than guess.

# completion-report

End every task with this report:

- **Completed** — what was done, with issue/PR links.
- **Not done / blocked** — what remains and why.
- **Open questions** — anything unresolved.
- **Suggestions** — clearly separated from what was done; nothing is implemented without approval.
- **Skills used** — the skills you opened and followed.
- **Anything mocked, assumed, or deviating from the plan** — "none" if none.

Be factual: no claiming completion for partial work; report what you checked and what you didn't.
